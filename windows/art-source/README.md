# Selected skill sources

Ten selected PNG sources rebuild the production skill resources: three Madara, three Sukuna and four Zoro mastery sheets. Only the compiled resources from windows/art enter the executable.

Use [CompileMadaraArt.cs](../../scripts/CompileMadaraArt.cs), [CompileSukunaArt.cs](../../scripts/CompileSukunaArt.cs) or [CompileZoroArt.cs](../../scripts/CompileZoroArt.cs) with the absolute project root. Each compiler explicitly names its selected input files. Detailed authoring notes are kept locally outside the public repository.
