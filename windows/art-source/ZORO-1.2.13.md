# Zoro mastery artwork - Windows 1.2.13

Cleanup note (November 13, 2026): only selected current production sources remain in the project. Unused drafts, superseded Zoro 1.2.12 sheets and historical review images were deleted at the owner's request. Generation names and prompts below remain as provenance, including references to retired files.

Built-in image generation produced seven source sheets, of which four are selected for the runtime. The 72 complete body poses use the mastery black bandana, forest-green robe and red sash; the 24 effect cels provide emerald crosscuts and a stronger finishing beam. Sources are copied unmodified from the generated originals. Starter artwork remains unchanged.

The weapon reference is the [official three-sword set](https://tamashiiweb.com/item/15253/): Wado Ichimonji, Sandai Kitetsu and Enma. The mouth grip is the centre of Wado's white handle between pommel and guard, with one blade projecting from that guard; the hands hold the other two swords. Enma uses purple hilt/trefoil guard cues and Sandai uses red hilt/cruciform guard cues. These are stylized small sprites, not dimensionally exact replicas. All 72 selected poses were visually reviewed for three blade tips, attached grips and connected anatomy. Finisher source refinement removed an extra underfoot blade-like arc in two poses.

Generated rows were not consistently aligned to exact 256px runtime cells. CompileZoroArt.cs now locates transparent gutters against the opaque silhouette (alpha >=180), then registers each complete pose with a common 240px baseline and a maximum 224px extent. It does not redraw swords, erase body pixels or modify the original PNGs. Soft outer background haze is excluded from bounding-box measurement; four source pixels of padding preserve the figure outline. The selected whole-pose crops/targets are logged under .local/zoro-registration-*-1.2.13.txt. All opaque artwork is retained; runtime body cels have clear boundaries without the prior near-black-pixel exception.

Only four compiled zoro_*.png atlases replace the previous four production resources; drafts, older sources, review GIFs and screenshots are never bundled or copied into the installed app.
