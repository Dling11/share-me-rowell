# PC studio art — 1.2.7

The matching customizable Boy/Girl sprites and their exact prompts are in [the default-avatar record](PC-CUSTOM-1.2.7.md). Optional `scripts/CompilePortraitArt.cs` compiles the desktop portraits at 128 pixels per complete cel with source alpha retained. The app embeds those PNGs and needs no authoring runtime. This changes Windows artwork only; Android 1.2.6 remains unchanged.

Built-in image generation, one original complete character per call, with the existing Yugi/Madara sheets as style references and transparency enabled. Selected source images are copied unchanged under android/art for shared provenance; this Windows redesign does not change the Android build or APK.
